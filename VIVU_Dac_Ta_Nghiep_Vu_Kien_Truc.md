# Đặc tả Nghiệp vụ & Kiến trúc VIVU

## 1. Kiến trúc hệ thống
- **Client**: React Native (Expo) cho nền tảng iOS và Android.
- **Backend**: Node.js/Express (hoặc Firebase/Supabase).
- **Database**: PostgreSQL (cho dữ liệu quan hệ) hoặc MongoDB (linh hoạt cho mạng xã hội).
- **Realtime Communication**: Socket.io hoặc Firebase Realtime Database (đảm nhiệm Message Home, Group Chat và Chat 1-1).
- **AI Integration**: Tích hợp OpenAI API / LLM cho module Trợ lý ảo ViVi.

## 2. Nghiệp vụ cốt lõi
- Quản lý định danh người dùng & Hệ thống Điểm uy tín.
- Hệ thống Matching và Quản lý Hoạt động nhóm.
- Xử lý bản đồ và Location-based services (LBS).
