# Kế hoạch Đánh giá (Testing Plan)

## 1. Unit Testing
- Test các component UI độc lập trên React Native (sử dụng Jest, React Native Testing Library).

## 2. Integration Testing
- Đảm bảo luồng dữ liệu từ Backend API trả về hiển thị chính xác lên danh sách bài viết, danh sách thành viên.

## 3. UI/UX Testing
- Xác minh 28 màn hình hiển thị đúng layout, màu sắc (gradient tím), typography trên các độ phân giải khác nhau.

## 4. Performance & Load Testing
- Kiểm tra tốc độ load Feed, độ trễ gửi nhận tin nhắn trong Group Chat và Chat cá nhân.

## 5. User Acceptance Testing (UAT)
- Thử nghiệm trên thiết bị thật thông qua Expo Go với nhóm sinh viên tại Đà Nẵng, Hà Nội, TP.HCM.
